## 실제 제출 폼 계약

- 제출 URL은 **HTTPS 1개 필수**이며 소스 URL은 받지 않음.
- 문서·장치 제출 파일은 **권장 1~4개**이며, 하나의 ZIP으로 묶어 제출 가능.
- 업로드 UI 전체 제한은 **파일 10개/합계 8MB**. 실제 제출 ZIP 용량을 사용자 로컬에서 확인.
- 재현·통과 확인 4가지와 AI·내 판단 3줄은 후행 채점에 중요하므로 공란으로 제출하지 않음.
- 제출 후 마스터 승인 전 BR-B는 열리지 않음.

## 사용자 확인과 공개 승인 두 가지는 별개

1. **공개 지표 승인:** 2026-10-21 기준 공식 요약·리추얼 자료의 정의와 수치가 맞는지 확인하고 공개할지 결정. 과제 원문의 새 리추얼은 2026-10-22까지 표시되므로 오래된 수치를 최신처럼 표현하지 않음.
2. **최종 파일 제출:** 실제 ZIP의 크기·SHA-256·내용을 확인하고, 제출 UI의 결과 URL·설명·파일을 입력해 제출.

브랜치 `issue-4-evidence-presentation`의 UI는 공개 지표를 위한 계약만 제공하며 **`evidenceMetrics`는 승인 이전까지 빈 목록**이다. 코드 PR 병합이 곧 개인정보 공개 승인은 아니다. 코드 검증은 55개 자동 테스트 및 정적 빌드를 기준으로 판단하며, npm registry 감사 API 타임아웃 시 보안 감사 결과를 **미확정**으로 표시한다.
