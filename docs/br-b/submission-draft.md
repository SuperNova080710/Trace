## 재현·통과 확인 4가지 (verificationNote 필드)

어디서 확인하나요: https://trace-eight-topaz.vercel.app/ech-beacon-explorer 또는 Trace 포트폴리오의 대표작 ECH Beacon Explorer 링크에서 확인합니다. 사용자 확인에 따라 새 시크릿 창에서도 계정 생성·로그인 없이 접근할 수 있습니다.

무엇을 하나요(3단계 이내):
1) 04 / INTERACTIVE RESEARCH LAB에서 트래픽 유형을 '정상'으로, 정상 트래픽 프로필을 'irregular-lognormal'로 선택하여 18건을 확인합니다.
2) '탐지기 간 판정이 다른 표본만 표시'를 체크해 3건을 확인하고, Trial ID를 눌러 Timing-only와 Multi-feature가 같은 트래픽을 어떻게 다르게 판정하는지 비교합니다.
3) '전체 조건 초기화'를 눌러 110건으로 되돌린 뒤 TP·FP·TN·FN, Precision·Recall·F1과 하단의 오탐·추론 비용 비교를 확인합니다.

무엇이 보이면 통과: 전체 110건(Beacon 50·정상 60)이 나타납니다. 전체 평가에서 Timing-only는 TP 50/FP 10/TN 50/FN 0, Multi-feature는 TP 50/FP 7/TN 53/FN 0이며, F1은 각각 0.9091/0.9346입니다. 110행 순수 추론 배치 중앙값은 약 0.080ms/1.409ms입니다. 연구에서 동결한 합성 Held-out 결과의 탐색이며, 실시간 네트워크 탐지는 아닙니다.

안 될 때: '전체 조건 초기화'로 필터를 복구합니다. 검색 결과가 없다면 Trial ID 검색어를 삭제하고 유형·프로필을 '전체'로 돌립니다. 새 시크릿 창에서 주소를 다시 열고, 계속 실패하면 브라우저·화면 폭·오류 문구와 재현 절차를 기록합니다.
