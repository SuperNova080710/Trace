# BR-B 제출 초안 (실제 제출 전 확인)

## 결과물 URL

https://trace-eight-topaz.vercel.app/ech-beacon-explorer

## 재현·통과 확인 4가지

1. **어디서 확인하나요:** 위 공개 URL 또는 Trace 포트폴리오의 대표작 ECH Beacon Explorer 링크에서 확인합니다. 로그인·계정 생성 없이 새 시크릿 창에서 열리는 것은 2026-10-22 사용자가 확인했습니다.
2. **무엇을 하나요 (3단계):** (1) Beacon 지터 0/10/30/50/70% 또는 정상 프로필을 선택합니다. (2) Trial ID를 선택하여 Timing-only와 Multi-feature의 동일 표본 판정을 확인합니다. (3) 두 모델의 오탐, Precision·Recall·F1 및 순수 추론 비용의 차이를 비교합니다.
3. **무엇이 보이면 통과인가요:** 논문 제목과 앱 소개가 보이고, 110개 합성 Held-out 표본을 필터링할 수 있습니다. 전체 정상 60건 중 오탐은 Timing-only 10건, Multi-feature 7건이며 Beacon 50건 재현율은 양쪽 모두 100%입니다. 선택 표본별 결과와 비용 비교(110행 배치 중앙값 0.080385ms 대 1.408802ms)가 표시됩니다. 실시간 탐지나 운영망 성능으로 주장하지 않습니다.
4. **안 될 때:** 새 시크릿 창에서 다시 열고 필터 초기화를 실행합니다. 데이터가 없으면 Trial ID 검색어를 비우고 유형/프로필을 '전체'로 바꿉니다. 계속 재현되지 않으면 사용 기기, 브라우저, 오류 문구 및 재현 순서를 기록합니다.

## AI와 내 판단 3줄 (검토 후 사용자 제출)

- **AI에게 맡긴 일:** T10 동결 연구 자료를 기반으로 공개 데이터 탐색 UI, 개별 Trial 비교, 성능·비용 시각화와 자동 테스트 코드를 작성하고 정적 빌드/검사를 구성했습니다.
- **내가 판단한 일:** T10의 합성 Held-out 110건을 근거로 평가 범위를 정했고, BR-A Trace 사이트를 유지하면서 BR-B 앱을 대표작에 연결하며, PR 병합·Vercel 배포·비로그인 시크릿 창 접근을 직접 확인했습니다.
- **AI 말을 안 들은 일:** AI가 처음 만든 큰 제목에서 실제 동료가 지적한 어색한 줄바꿈을 그대로 유지하지 않고, 첫 줄에 조사가 고립되지 않게 두 문장 블록과 글자 크기 수정을 요청했습니다. (실제 사용자 수정 요청과 부합)
