# Issue #2 — 자기소개 서사 사실 검증 계획

상태: 자료 확인 완료 / **본문 공개 승인 전**

## 기초 자료

- T09 최종 결과물: 실제 경험을 기준으로 삼는 1차 서사 자료
  - 날짜가 있는 행동 기록 6개
  - 최종 강점 지도, 본인이 직접 수정한 문장 2개, 자기소개서 초안
- T11 제출정본: 12장 자전적 **허구화** 소설
  - 장면 구성, 갈등과 회복의 문학적 흐름 참고
  - 대사·사건의 구체적 재현·감정 해석을 검증 없이 사실로 사용하지 않음
- 리추얼 원본의 공개 업로드 금지. 필요 시 로컬에서 사실 여부만 검토

> 본 문서는 공개 저장소에 있으므로 개인 리추얼 문장, 타인 발언, 원고 본문을 붙여 넣지 않습니다.

## 선택할 서사의 뼈대

1. **어려움** — 해결되지 않은 문제와 잘못된 접근을 마주한 장면
2. **전환** — 대상을 구간으로 나누어 확인하고 필요하면 기존 방법을 다시 시작하는 행동
3. **현재** — 기록, 가설 검증, 협업을 통해 스스로를 발전시키는 습관

검증 우선순위: 본인의 사실 확인 > 날짜가 있는 실기록 > T09에서 정리한 반복 행동 > T11의 서사적 장면.

## BRA-C 역량 축

- **자기조절력:** 상황을 분해하고 감정에 휩쓸리지 않도록 문제를 검증한 실제 행동
- **대인관계력:** 팀 협업·의사소통의 구체적 행동을 객관적 자료로 확인한 후 기술
- **자기동기력:** 포기/재시도/꾸준한 실행을 실제 날짜와 맥락으로 설명

대인관계력은 단순히 팀 프로젝트에 참여했다는 사실만으로 증명하지 않습니다.
